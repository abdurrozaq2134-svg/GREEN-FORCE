Penjelasan Proyek: Creastar project merupakan aplikasi yang berfungsi untuk membikin sebuah design menjadi website dan website yang dibuat oleh designer dapat dipublikasikan secara public dan diakses oleh seluruh peserta yang ingin mengikuti kegiatan tersebut, Creastar Project mempermudah desainer menguji ide dan meluncurkan halaman kegiatan tanpa koding rumit.

Fitur utama aplikasi:

Konversi Desain Otomatis
Platform mengubah tata letak visual menjadi kode web siap pakai. Desainer menghemat waktu pembuatan tampilan.

Publikasi Instan
Pengguna menerbitkan halaman web dengan satu klik. Domain publik langsung aktif dan siap disebar.

Manajemen Peserta Kegiatan
Pengunjung melihat detail acara, mendaftar langsung, dan mengakses materi kegiatan di satu tempat.

Responsif di Berbagai Perangkat
Tampilan web menyesuaikan otomatis saat dibuka lewat ponsel, tablet, atau komputer.

Instalasi : - Download php.exe menggunakan link ini https://www.php.net/downloads.php?os=windows (pastikan download versi terbaru)
	    - lalu download composernya menggunakan link ini https://getcomposer.org/download/ klik tulisan Composer-Setup.exe, lalu next 	      next terus, saat diminta file php.exe pilih file php.exe yang telah anda install sebelumnya
	    - jika semua Langkah sudah buka terminal ketik cd "alamat folder event builder", lalu ketik composer run dev dan lokasi file 	      tersebut adalah http://127.0.0.1:8000
Cara pakai : login menggunakan email anda, klik buat event baru, Mendesain halaman website event anda menggunakan logika logika event yang telah disediakan dan ketik tombol publish untuk mempublikasi aplikasi tersebut
